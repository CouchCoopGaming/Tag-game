# Vehicle mesh licenses

The shipped `Sedan_Mid_A` shell is original geometry built in this repo. It does not include a third-party car mesh, and it has no badges or logos.

Pass 13 takes proportions from a published 2025 Camry-class exterior table, not from a mesh. The sheet is the Toyota Camry eBrochure, model year 2025: https://www.toyota.com/content/dam/toyota/brochures/pdf/2025/my25-camry-ebrochure.pdf. Inches on that page: length 193.5, width 72.4, height 56.9, wheelbase 111.2, ground clearance 5.4, track 63.0. The shell uses the metre table for this pass: length 4.90, width 1.84, height 1.44, wheelbase 2.82, track 1.60, ground clearance 0.14, front overhang 0.96. No Toyota mesh, nameplate, or emblem is in the file.

Pass 12 looked for a CC0 sedan to start from. These were the candidates, and none is a modern midsize body:

- Kenney Car Kit, `sedan.glb`. CC0 1.0. https://kenney.nl/assets/car-kit and https://creativecommons.org/publicdomain/zero/1.0/. The body is a toy shell, 2.55 m long, 1.50 m wide, 1.15 m tall, 704 faces. Stretching it to 4.90 m does not produce a 2021–2025 hood, greenhouse, or deck.
- Quaternius LowPoly Cars. CC0 1.0. https://quaternius.itch.io/lowpoly-cars. Same class of low-poly prop cars, not a midsize sedan cage.
- Poly Haven. CC0. https://polyhaven.com/models. No sedan in the model library.

No badges or logos are on the shipped mesh.
