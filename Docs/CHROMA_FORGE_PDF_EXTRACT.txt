                                                        Slender Mold Art Bible · Version 1.1


 Seven factory molds woke when the Great Palette shattered. Not nations. Molds. Each remembers a different war — circuit,
 impact, neon, salt, honor, plastic, vacuum — but all of them run on one law: color is rank, technique, and voltage. This
 pack is the shareable brief. Attach the zip or this PDF to any chat, artist thread, or engine channel.

 These are concept models and a production system, not finished FBX files. Build seven slender humanoid meshes in Blender
 from the sheets. Recolor in Unity with the included scripts.

 Proportion lock — slender
 This revision kills bulk. Every mold shares the same lean fashion-toy body so a pink dummy and a deep-red knight still look
 like they came from one factory.

  Measure                                          Target

  Height                                           1.80 m hero · Army Man 1.72 m

  Heads tall                                       7.5–8

  Shoulder width                                   2.0–2.2 heads (never past 2.3)

  Waist                                            0.55–0.62 of shoulder

  Arm span                                         Equal to height

  Hands                                            +10% toy scale for readability

  Tris LOD0                                        8k–16k depending on mold

     If armor makes the shoulder wider than 2.3 heads, cut the armor. Do not fatten the body.

 The 33-charge palette
 Eleven hues. Three depths. Pale is a recruit. Standard is a veteran. Deep is a named piece that survived the box. Never bake

 Mask law: R = Primary, G = Secondary, B = Accent. Eyes and teeth stay on a second material or in the black of the mask.
 Tron Bots keep the body in Ink/Void and put the named hue into Accent + emission (Pale 1.5 / Standard 3.5 / Deep 6).

 Power system
 Manga wants named techniques. Production wants three verbs that every mold shares: Dash (mobility), Mark (paint the
 world in the unit hue), Break (spend shade depth on a finisher). Pale dashes farther and breaks weaker. Deep dashes shorter
 and breaks the screen. Hybrid rule: Primary chooses the animation set. Accent chooses the VFX color.

 Unity architecture
 One prefab per mold. Thirty-three palette assets. Zero duplicated materials per color. Push color through a
 MaterialPropertyBlock onto a single ChromaLit shader.

 Folder contract
     Assets/_Game/Characters/_Shared/Shaders/ChromaLit.shadergraph
     Assets/_Game/Characters/_Shared/Scripts/ChromaPalette.cs
     Assets/_Game/Characters/_Shared/Scripts/ChromaApplier.cs
     Assets/_Game/Characters/_Shared/Scripts/ChromaPaletteLibrary.cs
     Assets/_Game/Characters/_Shared/Palettes/*.asset
     Assets/_Game/Characters/RobotNinja|CrashDummy|TronBot|Pirate|Knight|ArmyMan|Astronaut/
 Shader Graph
 Sample greyscale albedo. Sample RGB mask. tint = Primary·R + Secondary·G + Accent·B. baseColor = albedo × tint. ORM
 pack is AO / Roughness / Metallic. emission = Accent × EmissiveMask × EmissionStrength. Feed a URP Lit master.

 Sockets on every mold
     socket_weapon_r · socket_weapon_l · socket_back · socket_hat · socket_fx_chest · socket_fx_eye
 Animation
 Unity Humanoid only. Mixamo for Idle / Walk / Run / Jump / Hit / Death plus three class attacks. Retarget once. Class extras
 live on Animator layers with Avatar Masks. Do not custom-rig seven skeletons.

 Build order
 1. Shader + 33 palettes on grey cubes. 2. Army Man. 3. Knight. 4. Tron Bot. 5. Dummy. 6. Astronaut. 7. Pirate. 8. Robot
 Ninja last — most silhouette-sensitive.

 Copy-paste artist brief
 Seven slender humanoid hero molds, collectible-toy style, 8–16k tris, Unity Humanoid, T-pose, applied scale, +Z forward.
 Greyscale albedo + RGB tint mask + packed ORM + optional emissive. Three tint zones only. Shared 7.5–8 head
 proportions, narrow waist, long limbs. Weapons socketed. No baked brand colors. Build Army Man first as the shader proof.
 Use the concept sheets in /concepts and the hex table in this bible.



                                The molds are the game. Color is the army. Keep those two ideas welded together.
